# ⚡ 48 小时速通一个学科

> 一位 MIT 研究生的方法：用 LLM + 结构化提问，48 小时内从零掌握一个全新领域。核心不在于工具，而在于提问方式。

## 背景

大多数学生花一整个学期才搞明白一个领域到底在争什么。这套方法通过三轮结构化提问，把这个过程压缩到 48 小时。

---

## 方法：三轮提问法

### 准备工作

不要只上传一本教材。尽可能多地收集该领域的资料作为上下文：

- 核心教材（多本）
- 重要学术论文
- 课程讲稿 / slides

将这些资料上传到你的 LLM（如 NotebookLM、Claude 等长上下文工具）。

---

### 第一轮：提取思维模型（约 20 分钟）

**Prompt：**

```
在这个领域里，所有专家都共通的 5 个核心思维模型是什么？

不是"总结一下"，不是"解释知识点"。
我要的是思维模型——那些教授要花好几年才能沉淀出来的东西。
```

**目的：** 不是获取知识点清单，而是获取专家看问题的底层框架。

---

### 第二轮：绘制争议地图（约 20 分钟）

**Prompt：**

```
现在告诉我，这个领域的专家在哪 3 个关键点上存在根本性分歧，以及双方最有力的论点分别是什么。
```

**目的：** 20 分钟内拿到一张完整的学科知识地图——争议点、共识、尚未解决的问题，一目了然。

---

### 第三轮：深度理解检验（约 6 小时）

**Prompt：**

```
生成 10 个问题，能区分出一个人是真的深度理解，还是只是死记硬背。
```

然后对照所有资料，逐一回答这些问题。

**每答错一题，追问：**

```
解释我错在哪里，我漏掉了什么。
```

---

### 结果

48 小时后，你可以和导师流畅对话，完全不被问倒。

## 核心理念

> 大多数人把 LLM 当高级划重点工具。
> 而顶尖学生把它当成读完该领域所有文献的私人导师。
>
> **一学期和 48 小时的差距，不在于学了多少内容，而在于你会不会问对问题。**
